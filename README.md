# Visual Computing Practical Work

This repository contains the practical assignments for the visual computing course.

## TP2 - 3D point projection
TP2 focuses on geometric projection of 3D points onto a 2D image plane. The project includes the implementation of a camera/projection pipeline and visualization of projected points.

## TP3 - Image processing
TP3 explores basic image processing techniques such as histogram creation, histogram stretching, histogram equalization, smoothing, and median filtering to improve and analyze image quality.

The exercises are organized in separate folders:
- `TP2/TP2/` for the projection assignment
- `TP3/TP3/` for the image processing assignment

Each folder includes the source code and a lab report in PDF format.
